UNIX-like x86-64 kernel written from scratch.

Uinxed is a monolithic UNIX-like x86-64 kernel, written from scratch in C. Runs on bare metal and virtual machines.

$
Quick Start →

Architected for Performance & Stability

A modern, self-contained kernel design — from boot to userspace

Limine Boot & SMP

Boots through the Limine bootloader in both UEFI and Legacy BIOS mode, and brings up every CPU core via SMP.

EEVDF Scheduler

Fine-tuned EEVDF scheduler with per-CPU runqueues and SMP load balancing. Priority Inheritance for robust mutex and futex semantics.

Memory Management

Higher-half direct map, a unified page cache with LRU reclaim, dirty-page writeback and readahead, and a swap subsystem.

Linux Compatibility

Implements the Linux x86-64 syscall ABI, so existing Linux userspace such as Alpine Linux can run on Uinxed.

Filesystems & Networking

UNIX-style VFS with FAT, ext2/3/4, NTFS and ISO 9660, plus an in-house IPv4/IPv6 TCP/UDP network stack.

Real Hardware

Drivers for storage, USB, input, audio, display and network devices. Runs in QEMU and on physical machines.

Get Started in Seconds

Compile and run Uinxed in your environment

  1. 1. Install the toolchain (Debian / Ubuntu)

    # Compiler, ISO tool and QEMU emulator
$ sudo apt install make gcc xorriso qemu-system-x86

  2. 2. Build the kernel and launch it in QEMU

    # Clone the repository and boot it inside a virtual machine
$ git clone https://github.com/ViudiraTech/Uinxed-Kernel.git
$ cd Uinxed-Kernel
$ make run -j$(nproc)

    Other distributions, booting on real hardware and more are covered in the README.
