# uinxed-kernel-website

The official website of [Uinxed](https://github.com/ViudiraTech/Uinxed-Kernel).

A plain static page — no build step, no frameworks:

- `index.html` — the page
- `stylesheet/style.css` — all styles (colors are CSS variables at the top)
- `script/script.js` — the "Copy" button in Get started
- `asset/` — images, favicon and self-hosted fonts (Source Serif 4 and JetBrains Mono, SIL Open Font License 1.1, see `asset/fonts/`)

To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.

To add a supporter, copy one `<li>` in the Supporters section of `index.html` (instructions are in a comment there).
